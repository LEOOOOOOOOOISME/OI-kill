## 2. Pages 单文件离线演示（dist\oikill-pages.html）

**流程**：`pages-entry.js` → esbuild（`--bundle --format=iife --minify --platform=browser`）→ `dist\_pages.js`；再把 `index.html` 的脚本区（从 `<script src="src/data/cards.js">` 到 UI 内联脚本开头 `<script>\nconst O = window.OIKill;`）整体替换为单块内联 `<script>`（bundle 内容）。被移除：**16 个外部 `<script src>` 标签**（9 引擎/数据 + net-api + 4 AI + adapter + lobby）**外加 fx.js / sfx.js 两个外部标签及其 3 个 `__dsh` 模块垫片**（bundle 已含 fx/sfx，垫片变死代码，一并清除）。`<style>` 与 UI 逻辑内联脚本**原样保留**。

**命名空间装配（入口自检，失败即抛错）**：`window.OIKill = 扁平引擎 api`（与浏览器 game.js 一致），再挂 `OIKill.ai.{difficulty,scorer,identityPolicy,heuristics}`、`OIKill.ui.{adapter,fx}`、`OIKill.sound.{sfx}`。引擎/AI 模块加载期各自捕获共享命名空间闭包（`NS.ai.*` 运行时查找，见 core.js/battle.js/tricks.js），`window.OIKill` 被替换不影响内部互引——与 game.js 浏览器分支同构。

**结构证据（grep）**：

```
<script src=  数量 = 0（期望 0）
内联 <script> 数量 = 2（期望 2：bundle + UI）
</script>     数量 = 2
<style>       数量 = 1（原内联样式保留）
const O = window.OIKill 出现在第 405 行（UI 内联脚本保留）
createLocalClient 出现在 bundle 中（×4 行）
__dsh* 残留 = 0
HTML 结尾 = </script></body></html>（原结构）
```

- **文件尺寸**：`oikill-pages.html` = **293,349 字节（286.5 KiB）**；其中 bundle = 191,402 字节（186.9 KiB，压缩后）。
- **离线行为路径**：浏览器 `file://` 打开 → UI `boot()` 检测 `file:` 协议直接 `bootLocal()`（http(s) 下 `/api/hello` 探活失败同样回落此路径）→ `O.ui.adapter.createLocalClient(O, {thinkMs:0, pid:0})` 直驱引擎 + 5 AI。
- **无浏览器运行时验证（vm 烟测，超出任务要求但顺带做了）**：在 Node `vm` 里加载 `dist\_pages.js`（`global.window=globalThis`，无 DOM/无服务器），断言 6 项命名空间装配全过，随后用 `createLocalClient` 驱动 **1 人类 + 2 AI 整局**：15 轮打至 gameover、winner=反贼、`g.over=true`、**120 牌守恒** 全绿 → 证明打包产物内的 LocalClient 链路真实可跑（即 file:// 演示行为）。

## 4. 单人链路端到端（build\single-e2e.mjs）

- **拓扑**：进程内 `http server` + 手写 `ws-server` + `room(mode=single, thinkMs:0, promptTimeoutMs:1500, turnTimeoutMs:4000, seed 固定)` 起真实服务端；客户端 = `src/ui/adapter.js` 的 **`createNetClient` 走 `global WebSocket`**（Node 24 原生 undici 实现，与浏览器同 API）连 `127.0.0.1`。
- **序列**：`join '我'`（首座=房主、`hello.mode=single`）→ `config({humanCount:1, aiFill:5, difficulty:'normal'})`（**轮询房间权威配置直到生效**，消除 WS 异步时序竞态——首轮唯一失败点，已修）→ `start` → 人类回合秒结束（`turn` 事件驱动 `endTurn`）、全部挂起提示按默认"否/放弃"应答（harvest/report/evo/discard 各走对应合法值，经 adapter 自动转 evolvePick/discardCards）→ 泵驱动 AI 直到 `gameover`。
- **结果：22/22 断言全过，exit 0，耗时 0.3s**（thinkMs:0 全速）。终局统计：**round=11、回合事件 57、state 快照 101、提示 20（全部定向到人类）、日志 202 行、winner=反贼**。
- 关键断言：setup `pid=0`、身份=主公、`seatToPid` 长度 6、`total=6`、大厅仅 1 个人类座位、引擎 `humanSet={0}` 其余 5 席 AI、开局与终局各一次 **120 牌守恒**（id===-1 衍生物不计，与 test.js A 套件同口径）、`gameover.payload.identity === null`、`g.over===true`、winner ∈ {主公方,反贼,内奸(摸鱼怪)}、**全程零 reject**、干净关停（客户端/房间/WS/HTTP 全部关闭，计时器清理）。
- 首轮 21/22：唯一失败 = config 断言在 WS 送达前立即读取 `room.config`（时序竞态），已改为 `waitFor` 轮询后稳定 22/22。未触碰引擎测试套件（按任务要求）。

## 6. 给 P9（SEA 流水线）的交接要点

1. **内存静态服务（必修）**：`bundle-lan.cjs` / `bundle-single.cjs` 现在运行时读盘服务静态文件，exe 里必坏。P9 需以 `--loader:.html=text`（及 CSS 等）把 UI 资源内联进 bundle，并给 http-static 加"内存路由"分支（或替换为内存 map 响应）；`dist\_pages.js`/`oikill-pages.html` 可作为 UI 资产来源。
2. **BUILD_MODE 已注入**：两个 bundle 已带 `BUILD_MODE='lan'|'single'` 编译常量（当前源码未消费，P9 可据此做模式分支，如 single 跳过 lobby）。
3. **SEA 步骤**（recon-02 C.2，按现状核对）：`sea-config.json`（main 指向 dist bundle）→ `node --experimental-sea-config` → 复制**同版本 node.exe（v24）**→ `npx postject`（需 `npm i -D postject`，本阶段未装）注入 `NODE_SEA_BLOB`。exe 须保持控制台子系统（boot.js 依赖 stdout/stdin，见 boot.js 头注释）；未签名 exe 的 SmartScreen 提示属预期。
4. **可复用的绿色基线**：`npm run build`（pages+server）、`npm run e2e:single`（22 断言）、`node build\bundle-pages.mjs` 的自检会挡住 index.html 脚本区结构变化。
