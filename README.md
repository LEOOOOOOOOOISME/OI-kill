# 《OI杀》—— 算法竞赛主题桌游

> 让每一种身份都有胜算，让每一个职业都有独特的战术价值，让卡牌进化成为“惊喜”而非“碾压”。

《OI杀》是一款以算法竞赛（OI）文化为背景的多人卡牌对战桌游。玩家将扮演 **Au 选手（主公）**、**Ag 选手（忠臣）**、**反贼**、**摸鱼怪（内奸）** 等身份，选择 **萌新**、**神犇**、**毒瘤出题人** 等 **19 种职业**，利用 **做法假了**、**WA**、**CCF捐款**、**咖啡** 等充满梗的 **172 张** 卡牌展开博弈。游戏融合了身份隐藏、技能组合、卡牌进化以及随机事件，既考验策略，又充满欢乐的“评测机式”意外。

---

## 一、身份与胜利条件

| 身份 | 体力 | 特殊能力 | 胜利条件 |
|------|------|----------|----------|
| **Au 选手（主公）** | 5（+1） | 明置身份 | 消灭所有 **摸鱼怪** 和 **毒瘤**（反贼） |
| **摸鱼怪（内奸）** | 4 | 开局获得 **3枚颓废标记**，可于回合开始或濒死时移除1枚，回复1体力或摸2牌 | 存活到最后（成为唯一生还者） |
| **毒瘤（反贼）** | 4 | 无额外能力 | 击杀 **Au 选手** |

> 注：其他身份（如忠臣）规则与标准身份局类似，具体人数配置可根据玩家数量调整。

## 二、职业与技能（19 种职业，详见《需求.txt》第八章）

每个职业拥有独特的 **被动** 与 **主动** 技能，并配有 **觉醒技**（见趣味机制），体力值经过平衡调整。

| 职业 | 体力 | 技能 |
|------|------|------|
| **萌新** | 4 | 被动·问问题：成为卡牌唯一目标时摸1牌（每回合限一次）。 |
| **蒟蒻** | 4 | 被动·抱大腿：回合开始空手摸1。主动·退役（濒死技）：弃所有手牌和装备，回复1体力。 |
| **划水怪** | 4 | 被动·随缘：摸牌阶段可改为摸1牌+从弃牌堆拿1基本牌。主动·摸鱼：回合结束时若未造成伤害，摸1弃1。 |
| **神犇** | 4 | 被动·碾压：黑色手牌当【AC代码】。主动·AKIOI：弃2牌，本回合可额外使用两张【AC代码】，且这些杀伤害+1（限2张）。 |
| **毒瘤出题人** | 3 | 被动·卡常：每回合限一次，使用【AC代码】时可判定，若为黑桃则不能被【WA】响应。主动·出原题：弃两张同花色，观看并弃置目标一张手牌，其摸1。 |
| **退役选手** | 5 | 被动·回忆：受伤判定，黑桃减伤1。主动·挣扎：回合开始可扣1血摸2。 |
| **金牌教练** | 4 | 被动·集训：回合结束指定一人，各摸1。主动·谈心：有人死亡时可弃1牌阻止，回复至1血（一局一次）。专属牌·模拟赛：出牌阶段，选择至多三名其他角色，这些角色必须打出一张【AC代码】否则受1点伤害。 |
| **女装大佬** | 3 | 被动·女装：成为锦囊目标时摸1牌（每回合限一次）。主动·直播：弃一张红色牌，观看一名角色手牌并获取其中一张。专属牌·女装直播：所有角色摸1牌，然后所有角色（除你）弃1牌，你获得弃置牌中的一张。 |
| **传奇Au选手** | 4 | 被动·不败：因卡牌效果失去体力时，每回合限一次可防止。主动·封神：展示所有手牌，选择至多两名角色各造成1点伤害（一局一次）。 |

## 三、卡牌构成（总计 172 张，详见《需求.txt》第三章）

### 1. 基本牌（63 张）
- **做法假了** ×27（攻击牌，可被 WA 闪避）  
- **WA** ×18（防御牌）  
- **CCF捐款** ×12（回复牌）
- **咖啡** ×6（强化/濒死自救）

### 2. 装备牌（18 张）
| 类型 | 名称 | 效果 |
|------|------|------|
| 武器（4） | 树状数组（距1） | 命中后可看目标手牌 |
| | 线段树（距2） | 被闪可摸1 |
| | 平衡树（距3） | 被闪可弃牌强制命中 |
| | 莫队算法（距2） | 出杀时可额外弃1牌指定另一目标 |
| 防具（4） | 并查集 | 弃牌当闪 |
| | 记忆化搜索 | 受伤判定，红桃减1伤 |
| 进攻坐骑（5） | 快速读入 | 计算距离-1，功能牌距离限制-1 |
| 防御坐骑（5） | 内存屏障 | 别人算距离时+1 |

### 3. 功能牌（36 张）
- 对拍 ×7、爆零 ×3、停课集训 ×2、摸鱼 ×5、抄袭代码 ×5、请家长 ×3、O2优化 ×3、重构 ×2  
- 专属牌：模拟赛 ×1、女装直播 ×1  
- **手动测评** ×1：弃1牌，将当前判定牌花色视为红色或黑色（二选一），用于改判。  
- 灵活位 ×1（可自行设计）

### 4. 彩蛋牌（6 张，不占原卡位）
抽到后立即展示并生效，制造欢乐混乱（详见“趣味机制”）。

> 牌堆总计 117 张，抽空时重洗弃牌堆。

## 四、进化系统

卡牌在满足特定条件后可进化为更强形态，**每人每局最多进化3次，每回合最多1次**（可通过【系统重构】额外突破）。

| 原牌 | 进化条件 | 进化效果 |
|------|----------|----------|
| AC代码 | 命中并造成掉血 | **AK代码**：伤害+1，被WA抵消时你摸1牌 |
| WA | 成功抵消AC代码 | **完美防御**：抵消后摸1并回1体力 |
| RE | 用此牌将濒死救回 | **大紫荆花**：额外回1体并摸1牌 |
| 对拍 | 对拍中获胜 | **WC对决**：你与目标轮流出AC代码（你先），败者受2伤 |
| 抄袭代码 | 获得目标装备牌 | **暴力抄袭**：获得目标任意一张牌（无视距离） |
| 请家长 | 目标因此弃了装备 | **退学警告**：目标额外弃一张手牌，否则受1点伤害 |
| O2优化 | 使用后本回合造成过伤害 | **O3优化**：使用一张AC代码，伤害+2且无视距离 |
| 线段树 | 装备后连续3个自己回合造成伤害 | **主席树**：攻击距离+3；被闪时可弃1牌令其无效 |
| 并查集 | 发动并查集效果成功抵消杀 | **路径压缩**：改为弃一张与攻击牌同花色的手牌即可（无则正常弃） |
| 重构 | 使用重构并进化了一张牌 | **系统重构**：从弃牌堆选1张牌进化并加入手牌，本回合可额外进化一次 |

## 五、趣味机制（强心针）

### 1. 评测机疯狂事件（每回合随机触发）
每轮开始时翻开牌堆顶一张牌，根据花色触发全局事件，持续一回合：

| 花色 | 事件名 | 效果 |
|------|--------|------|
| ♠ 黑桃 | 毒瘤评测机 | 所有【AC代码】伤害-1，但无视【WA】 |
| ♣ 梅花 | 暴力评测机 | 所有【AC代码】伤害+1，但使用者受1点伤害 |
| ♥ 红桃 | 慈善评测机 | 所有人使用【AC代码】无次数限制 |
| ♦ 方块 | 随机评测机 | 成为【AC代码】目标时判定：红桃=WA，黑桃=伤害+1 |

### 2. 觉醒技（每个职业一局一次）
达成条件后触发强力效果，制造“名场面”：

| 职业 | 觉醒条件 | 觉醒效果 |
|------|----------|----------|
| 萌新 | 首次体力≤2 | “我还能学！”：永久摸牌阶段多摸1 |
| 蒟蒻 | 使用【退役】自救成功 | “退役是不可能的”：+1体力上限并回1血 |
| 划水怪 | 连续两回合未造成伤害 | “终极摸鱼”：摸3牌，【摸鱼】额外摸1 |
| 神犇 | 同一回合用【碾压】打出2张以上AC代码 | “AK全场”：下一张AC代码可指定任意数量目标 |
| 毒瘤出题人 | 【卡常】成功≥2次 | “全员卡常”：全场其他角色下回合不能使用WA |
| 退役选手 | 【回忆】累计防止2点伤害 | “老兵不死”：回2血摸2牌 |
| 金牌教练 | 用【谈心】救活一名角色 | “名师出高徒”：被救者与你各获1张AC代码 |
| 女装大佬 | 通过【直播】看过2名不同角色手牌 | “公开处刑”：目标展示手牌并弃掉所有红色牌 |
| 传奇Au选手 | 首次使用【封神】 | “传奇不朽”：本局剩余伤害+1 |

### 3. 彩蛋牌（6张）
抽到立即展示，效果搞笑且微妙（无法被抵消）：
- **女装求AC**：指定角色给你一张手牌，否则你回1血。
- **“我样例过了！”**：若无AC代码则摸2，若有则弃1张AC代码。
- **评测机崩溃**：弃牌堆所有AC代码回牌堆重洗，所有玩家失去1体力。
- **原题大战**：所有角色展示并弃置最大点数的手牌。
- **学长讲题**：指定角色摸2，你从弃牌堆获1张WA。
- **退役失败**：1血角色回1，满血角色受1伤害。

### 4. 嘲讽语音与囧闻
- 每个职业触发技能或觉醒时播放 OI 圈经典语录（可关闭）。
- 每局结束后生成“本局囧闻”，记录搞笑瞬间，便于分享。

## 六、游戏流程简述

1. **准备**：分发身份、职业、初始手牌（通常4张）。  
2. **回合流程**：  
   - 回合开始（触发觉醒检测、颓废标记使用等）  
   - 判定阶段（评测机事件触发）  
   - 摸牌阶段（可配合技能）  
   - 出牌阶段（使用卡牌、装备、技能）  
   - 弃牌阶段（手牌上限=体力值）  
   - 回合结束（结算摸鱼等技能）  
3. **胜负判定**：根据身份目标，直至达成胜利条件。

## 七、设计理念与平衡性

- **身份平衡**：Au选手多1血，摸鱼怪有颓废标记，避免首轮猝死和内奸无力。  
- **职业平衡**：每个职业体力值与技能强度匹配，弱势职业有续航或翻盘手段。  
- **卡牌分布**：攻防回复比例合理，花色分布支持特定职业。  
- **进化上限**：每局最多3次，避免单卡过度碾压。  
- **趣味层不破坏核心**：随机事件、觉醒、彩蛋均为临时或一次性效果，增加戏剧性而不失竞技性。
