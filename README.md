# 《OI杀》玩家手册

欢迎来到OI（信息学竞赛）的战场！这是一款3-9人参与的回合制身份卡牌桌游。你将扮演OI圈中的一位“职业选手”，目标是利用卡牌和技能，完成自己所属“身份”的秘密任务。

**一句话概括：** 这是一场用“做法”、“WA”、“CCF捐款”等OI黑话进行战斗的“三国杀”。

---

## 1. 游戏目标与身份

游戏开始前，你会秘密获得一个身份，它决定了你的队友和胜利条件。

| 身份 | 别名 | 你的任务（胜利条件） |
| :--- | :--- | :--- |
| **Au选手** | 主公 | **生存并获胜**。你需要和忠臣一起，消灭所有反贼和内奸。你的身份是公开的，体力上限+1。 |
| **Ag选手** | 忠臣 | **保护主公**。你的目标是帮助主公杀死所有反贼和内奸。 |
| **反贼** | 红客 | **推翻主公**。你的目标是杀死主公。 |
| **摸鱼怪** | 内奸 | **活到最后**。当主公死亡时，场上必须只剩下你一个存活玩家。你开局有3枚【颓废标记】用于保命。 |

**胜利判定顺序：**
1.  **反贼赢**：主公死亡，且场上还有反贼活着。
2.  **摸鱼怪赢**：主公死亡时，除了摸鱼怪自己，场上没有其他活人。
3.  **主公方赢**：所有反贼和内奸都死亡。

---

## 2. 游戏准备

1.  **满员开局**：房间必须满员（3-9人）游戏才开始。满员后，每人发4张初始手牌。
2.  **随机职业**：你会从19种OI职业（如“神犇”、“蒟蒻”）中随机获得一个，每个职业有独特的技能和体力值。
3.  **座位与距离**：所有人围成一圈。你与相邻玩家的**距离为1**。攻击时必须考虑距离。

---

## 3. 回合流程

游戏按顺时针轮流进行。轮到你时，按以下顺序执行：

1.  **回合开始**：触发一些技能效果（例如摸鱼怪可选择使用【颓废标记】）。
2.  **判定阶段**：检查你面前是否有“延时锦囊”（如【水群】、【断网】），有则需要“判定”（翻牌看花色）来决定是否生效。
3.  **摸牌阶段**：从牌堆摸2张牌。
4.  **出牌阶段（核心）**：
    - 你可以使用任意张牌，但**【做法假了】（攻击牌）每回合默认只能使用1次**。
    - 你可以：攻击别人、使用锦囊、装备武器/防具/坐骑、或发动职业技能。
    - 点击【结束出牌】进入下一阶段。
5.  **弃牌阶段**：你的手牌数不能超过你当前的体力值。超出部分必须弃掉。
6.  **回合结束**：触发一些技能效果，然后轮到下家。

## 4. 核心机制

### 卡牌类型
- **基本牌**：
    - **【做法假了】**：攻击牌。对距离内的玩家使用，造成1点伤害。
    - **【WA】**：防御牌。被【做法假了】攻击时打出，可以抵消伤害。
    - **【CCF捐款】**：回复牌。对自己使用，回复1点体力。
    - **【咖啡】**：强化/自救牌。出牌阶段使用，让下一张【做法假了】伤害+1；濒死时使用，回复1点体力。
- **锦囊牌**：功能各异，如【摸鱼】（摸2张牌）、【爆零】（弃别人牌）、【数据加强】（AOE群攻）。
- **装备牌**：装备后获得持续效果，分为武器（加攻击范围/特效）、防具（加防御）、坐骑（调整距离）。
- **彩蛋牌**：抽到立即生效，充满随机趣味。

### 攻击与防御
- 使用【做法假了】攻击时，目标可以打出【WA】来“闪避”。
- 如果对方没有【WA】或不想出，则受到1点伤害。
- **攻击范围**：默认只能攻击距离1的玩家。装备武器可以增加攻击范围。

### 距离规则
- 你和目标之间的最短路径（顺时针或逆时针）为距离。
- 阵亡的玩家不计入距离计算。
- 进攻坐骑（快速读入）：你到别人的距离-1。
- 防御坐骑（内存屏障）：别人到你的距离+1。

### 濒死与救援
- 当你的体力降到0或以下时，进入濒死状态。
- 此时，你可以自己使用【咖啡】或请求队友使用【CCF捐款】等效果救援。
- 如果无人救援，你宣告阵亡，退出游戏。

### 判定
- 需要“判定”时，翻开牌堆顶的一张牌，只看它的**花色**（黑桃、红桃、梅花、方块）来决定结果。
- 例如：【水群】判定，若为**红桃**则无事发生，否则你跳过出牌阶段。

## 5. 职业简介（部分）

你有19种职业可选，每种都来自OI圈的梗。这里列举几个代表性职业：

- **神犇（体力4）**：大佬级人物。可以把黑色手牌当【做法假了】用，还能开大“AK全场”增加伤害。
- **蒟蒻（体力4）**：菜鸟自嘲。回合开始没手牌能白摸一张，濒死时还能“退役”自救。
- **毒瘤出题人（体力3）**：专门恶心人。出的【做法假了】有概率无法被【WA】闪避。
- **女装大佬（体力3）**：靠女装迷惑对手。成为锦囊目标能摸牌，还能偷看并拿走别人的手牌。
- **评测姬（体力3）**：评测系统的化身。受伤能减伤，还能“重测”自己的手牌。
