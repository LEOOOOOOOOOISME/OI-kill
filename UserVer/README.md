# OI杀 v4.0 重构版（v4-web）

按 `requirement.txt` v4.0 从零重构的可玩实现。**原 C++ 版本未被覆盖**（本文件夹全新）。

## 文件

| 文件 | 说明 |
|---|---|
| `game.js` | 纯逻辑游戏引擎（无 DOM），浏览器/Node 双端可运行 |
| `index.html` | 可玩 UI（白/黑双主题 · 命名双轨 · 尺寸缩放 · 点击出牌/选目标/WA响应/自动托管） |

## 运行

- **浏览器**：直接打开 `index.html`（你是 0 号玩家，其余为 AI）。
- **引擎回归测试**：`node test.js`（若存在）或临时 `node -e` 调用 `game.js`。

## 已实现的 v4.0 规则

- 3~6 人身份局（主公/忠臣/反贼/内奸）+ 身份分配表 + 胜利判定顺序 + 死亡翻牌（内奸不公开）+ 击杀奖惩（反贼摸3/主公打忠臣-1）
- 灵感经济：起始3/主公首回合5、上限+1封顶12、回复4、减费铁律（最低1费/同牌最多一次减额取最大）、领域亲和（主领域牌每回合首次-1）、评测机连发、慈善评测机事件
- 120 张牌堆（4 类）+ 花色点数 + 题海战术（摸空洗回、全体-1体力）
- 基本牌：做法假了/WA(响应1费)/CCF捐款/咖啡(伤害+1与濒死自救)
- 锦囊：对拍/爆零/摸鱼/抄袭代码/停课集训/O2优化/卡评测机/骗分/申诉/玄学优化/数据加强(AOE)/评测机抽风(AOE)/CCF放水/题解大会/水群/断网/UB(延时+判定)/删库/小抄/复盘 + 8 张欢乐牌（含卖队友转嫁、躺赢禁攻、开小号复制、机房断电、感谢CCF等）
- 装备 20（武器11/防具9，两栏限1、换装弃旧、每回合首次计数跟随玩家）：评测机连发/管理员权限/树状数组/线段树/双指针/冷数据/平衡树/手写快排(未实装)/放手一搏(未实装)/拔网线/不死心 + 玄学判题/黑名单/AC保护/并查集/记忆化搜索/防火墙/内存加固/双核/备用电源
- 单位 8（一击必杀制）：守擂挡刀（挡一次即消灭）、速攻、亡语、部署特效
- 守擂拦截、战斗裁决流程（玩家→玩家可出WA、单位只打单位、单位永不打玩家）
- 判定：延时锦囊判定、判定牌置回牌堆底；濒死救援链（蒟蒻退役→颓废标记→金牌教练谈心→备用电源→咖啡）；觉醒（体力≤上限一半立即触发，部分职业效果已实装）
- 评测机事件 4 种（毒瘤/暴力/慈善/随机）；45 秒限时（引擎未强制，UI 未显示倒计时）
