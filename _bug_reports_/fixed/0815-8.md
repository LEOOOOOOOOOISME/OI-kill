## 修复的 Bug（game_engine.cpp / network_server.cpp）

1. **神犇碾压无限循环（严重）**
   - 碾压路径 isVirtual=true → 直接命中分支 `if (!isVirtual && !discarded)` 永不弃牌 →
     同一张黑牌可无限碾压刷屏（实测本回合 76 次）
   - 修复: performAcAttack 增加 consumeCard 参数——碾压传 true(真实弃牌), 手写快排虚拟AC传 false
2. **专属职业卡报"未实现的卡牌"误导**
   - 女装直播/封神/模拟赛 被非对应职业使用时落到兜底"未实现的卡牌"
   - 修复: 明确提示 "仅X职业专属"
3. **AC 使用次数限制静默失败**
   - 次数已达上限时 `return false` 无 error → 客户端无感知, 反复尝试
   - 修复: 返回错误消息 "本回合使用【做法假了】次数已达上限"
4. **pending 超时死锁（严重）**
   - resolvePendingTimeout 只在 getStateJson(广播) 时调用; 若玩家挂机且无人操作 → 广播停止 →
     pending 永不超时 → 游戏永久卡死
   - 修复: 服务器新增后台超时线程 (800ms 轮询所有房间, 超时自动处理并广播)
5. **join_room 未加入房间报"未登录"误导**
   - 不在任何房间时 join_room 返回"未登录"
   - 修复: 改为 "你不在任何房间中，请先创建或加入房间"
