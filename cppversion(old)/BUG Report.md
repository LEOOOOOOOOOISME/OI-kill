# BUG Report — OI杀 自动化对局测试（2026-08-15）

> 测试方式：Node 自动化客户端（test_game.mjs）模拟 4 玩家完整对局 + 长跑回归，
> 对照《需求.txt》(v3.0) 逐项核对。以下为测试中发现/观察到的全部问题。
> 标记：✅已修复（提交内可查） / ⚠️未修复（建议后续处理） / 💡潜在风险（低概率/设计权衡）

---

## 🔴 严重（影响对局进行）

### BUG-1【已修复】神犇·碾压 无限循环（同一张黑牌反复碾压）
- 现象：慈善评测机事件下，神犇用一张黑色手牌【碾压】，本回合刷屏 76+ 次"碾压将 ♠7 X 当作AC使用"
- 根因：碾压路径 `performAcAttack(card, true)` 的 isVirtual=true，直接命中分支
  `if (!isVirtual && !discarded)` 永不弃牌 → 黑牌始终在手 → 每 tick 可再碾压
- 修复：performAcAttack 增加 consumeCard 参数（碾压=true 真实弃牌；手写快排虚拟AC=false）
- 对应需求：8.4 神犇碾压（黑牌当 AC 使用，进攻击流程）

### BUG-2【已修复】pending 超时死锁（玩家挂机/无操作 → 游戏永久卡死）
- 现象：某 pending 无人响应且之后无任何玩家操作 → 日志停止，游戏永久卡住
- 根因：resolvePendingTimeout 只在 getStateJson（广播）时被调用；无操作 → 无广播 → 超时逻辑永不执行
- 修复：服务器新增后台超时线程（800ms 轮询所有房间，到期自动处理并广播）
- 对应需求：17.7 响应限时（超时视为不打出）

## 🟠 一般（影响体验/信息）

### BUG-3【已修复】专属职业卡被非对应职业使用时报"未实现的卡牌"
- 现象：非女装大佬使用【女装直播】、非传奇Au使用【封神】、非金牌教练使用【模拟赛】
  → 服务器报"未实现的卡牌"（误导）
- 修复：明确提示"【X】仅X职业专属"
- 对应需求：9.3 各锦囊的专属标注

### BUG-4【已修复】AC 使用次数限制静默失败（客户端无感知）
- 现象：本回合【做法假了】次数用完后，再次攻击被静默拒绝（useCard 返回 false 无 error），
  客户端反复尝试无反馈
- 修复：返回错误消息"本回合使用【做法假了】次数已达上限"
- 对应需求：4.4 AC 使用次数限制

### BUG-5【已修复】join_room 未加入房间时报"未登录"
- 现象：已登录但不在任何房间时，WebSocket join_room 返回"未登录"（误导）
- 修复：改为"你不在任何房间中，请先创建或加入房间"

### BUG-6【未修复】AOE 伤害为 0 时日志文案误导
- 现象：【毒瘤评测机】事件下（AC 伤害-1），AOE 基础 1 伤被减为 0，
  日志仍打印"无WA响应【评测机抽风】，受到0点伤害"
- 建议：dmg<=0 时改打"未受到伤害（毒瘤评测机减免）"或不打伤害日志
- 对应需求：11章 AOE 说明（事件同样作用于 AOE）

## 🟡 潜在风险 / 边界（低概率或设计权衡）

### BUG-7【风险】evolution_select 响应找不到候选牌 → pending 挂起到 15s 超时
- 场景：进化候选指向的牌若被【重构】【申诉】等从弃牌堆拿走（候选者非本人时），
  响应时在弃牌堆/手牌/装备区均找不到 → `return false` → pending 挂起
- 现状：已由 BUG-2 的超时线程兜底（15s 后自动清候选继续），但会造成 15s 停顿
- 建议：响应失败时直接清空该候选并继续，而非挂起到超时

### BUG-8【风险】日志数组固定保留 50 条
- 长局（>50 条日志）时旧日志被挤出，玩家无法回看早期事件；非 bug 但可考虑增加上限或分页

### BUG-9【风险】pending 期间模态遮罩遮挡"查看弃牌堆"按钮
- 待响应时全屏模态（#modal-mask z-index 900）覆盖牌堆栏，玩家无法同时查看弃牌堆
- 次要体验问题，可考虑遮罩内提供入口

### BUG-10【风险】测试工具相关（非游戏 bug）
- 自动化脚本在 state 广播延迟下会产生竞态错误（"请先处理需要响应的操作"、
  "还没轮到你出牌"、"体力已满"）——服务器防护均正确拒绝，属脚本时序问题
- 多目标攻击（放手一搏/AK全场）、找代打（2目标）、O2优化 等复杂交互未在脚本中完整覆盖

## ✅ 测试验证结论
- 完整对局多次跑通：17~37 回合正常 GAME OVER（胜负判定正确、阵亡/濒死/救援链工作）
- 长跑回归：321 回合稳定运行无死锁（残局继续）
- 已覆盖机制：进化（实锤/暴力抄袭/浓缩咖啡等）、AOE（含进化暴走）、延时锦囊（水群/断网）、
  彩蛋牌、事件轮转、链式前向星、碾压、对拍、随缘、颓废标记、TLE/CE 裁决等
- 未覆盖（建议后续专项测试）：3 人/9 人局、UB 闪电、题解大会选牌、代码审计、女装直播、
  玩家中途退出/掉线重连、挂机超时（超时线程已兜底）
