## 1. 回合开始合法摸牌来源推导表（退役选手视角：⑤弃牌(弃至上限5) → 下次①回合开始断言点）

断言点在 `startTurn`（①回合开始：觉醒判定 + 锁定技结算）之后、②判定/③摸牌之前，因此窗口内合法来源为"他人回合 + 自身⑥回合结束 + 自身①"。

| 来源 | 最大摸牌 | 规格依据（requirement.txt）与引擎实现 |
|---|---|---|
| **挣扎**（锁定技） | +2 | L523「挣扎(锁定)：回合开始体力>1时-1体力摸2」；game.js L383 |
| **觉醒「回2血摸2」** | +2 | L523 觉醒效果列「回2血摸2」；觉醒规则 L513、L581-583（立即触发；回复不超上限，溢出改摸等量牌）；game.js L841。**溢出不可能**：触发条件 `hp ≤ ⌊maxHp/2⌋`，退役选手 maxHp∈{5, 6(内存加固 L415), 7(主公+2)}，触发时 hp≤3，+2 后 ≤5≤maxHp，恒无溢出，故固定 +2 |
| **玄学优化 / 馈赠** | +2/张（牌堆共2张） | L354「目标摸 2 张」；game.js L36（desc）、L109（gift: 2） |
| 学长·讲题 | +1/学长回合 | L526「让一名其他玩家摸1」 |
| 金牌教练·集训 | +1 | L524「回合结束与一名随机其他存活玩家各摸1」；game.js L460 |
| 题解大会 | +1 | L358「…各选 1 张」 |
| 金牌教练·谈心(觉醒) | +1 | L524 觉醒效果「被救者与你各从弃牌堆拿1张做法假了」；game.js L667-669 |
| 自身⑥进化取回 | +1 | L559-560「进化后卡牌改名、标记进化、获得新效果，加入手牌」；game.js L810-822（守卫/删库路径从弃牌堆取回） |

**已知失败轨迹（seed=29，引擎修复前）**：5 + 2(玄学优化×1) + 2(觉醒) + 2(挣扎) = **11 张**。旧容忍 +5 上限为 10，对合法轨迹误报 1 张。

**根因**：旧注释写「觉醒+1」，是把萌新觉醒「摸牌阶段多摸1」（L527）误套到了退役选手；退役选手觉醒实际为「回2血摸2」= +2，恰好差 1。→ 回合开始容忍校准为 **+6**（上限 11）。

**为何不把上表全部来源求和（+13）**：按任务「不盲目放宽」原则，容忍度按已验证会实际发生的合法轨迹校准。其余来源（第二张玄学优化、学长、集训、题解大会、谈心、进化取回）在当前 40 个固定 seed 轨迹中未与「挣扎+觉醒+玄学优化」同窗口叠加；全量求和会把上限推到 18 张、使断言彻底失效。实测 40 seed 回合开始最大超额 = +5（seed=19 甲：进化取回+1 + 觉醒+2 + 挣扎+2 = 10 张，已顶在旧容忍边缘），+6 覆盖已知 +6 合法轨迹并保留护栏灵敏度。若未来轨迹出现更高合法叠加（如玄学优化×2+觉醒+挣扎=+8），按本表重新标定。

## 2. 弃牌后断言标定（+2 → +3）

任务要求"阅读表明同样标定错误时才调整"。阅读表明其同样差 1：

- 划水怪觉醒「终极摸鱼」：回合结束未造成伤害→摸2，**+2**（L522；game.js L454）
- 金牌教练·集训：**+1**（L524）
- 进化取回手牌：**+1**（L560「加入手牌」；game.js L810-822）
- 「终极摸鱼」与「集训」互斥（不同职业），但进化取回可与任一叠加 → **合法最大 = 2+1 = +3**

**实证**：seed=15 round=6，丙(划水怪)同一⑥内连续结算「【终极摸鱼】摸2」与「进化!【删库】→【清空回收站】(从弃牌堆取回加入手牌)」，弃牌后 hand=7=上限+2（当时⑤末仅 4 张，未触发误报）；若⑤末为 5 张则为 8=上限+3，旧 +2 容忍会对合法状态误报 → 校准为 **+3**。
