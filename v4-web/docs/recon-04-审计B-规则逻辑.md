# 审计B：规则逻辑 vs requirement.txt（v4-web/game.js）

- 审计对象：`v4-web/game.js`（2144 行，纯逻辑引擎）vs `requirement.txt`（v4.0 唯一权威规范）。
- 方法：通读 requirement.txt 全文；对 game.js 按区间精读（1-360 / 360-760 / 760-1160 / 1160-1600 / 1600-2144）+ 定点 grep 复核缺失项。
- 结论概览：**不符 H×2、M×15、L×12，需复核×12**。规则骨架（身份/胜利/灵感经济/铁律1-2/濒死链/双轨/事件主体）实现完整度较高，主要问题集中在：判定牌去向反向实现、觉醒 switch 重复 case、多职业觉醒升级未实现、特判系统缩水、事件对 AOE 无效、亡语/进化表缺项。

**H-1 判定牌置回牌堆顶，而非需求规定的牌堆底**

- 修复：改为 `g.deck.unshift(c)`。

**H-2 checkAwaken 的 switch 重复 case，导致 4 职业觉醒效果错误**
